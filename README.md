# Atlas Sprint

Atlas Sprint is a mobile-first geography trainer built as an installable PWA.

It covers:

- Flags
- Capitals
- Country outlines
- Tap-the-map drills
- Neighbor and region intuition
- Major oceans, seas, rivers, mountain ranges, deserts, and lakes

Progress is stored locally in the browser with XP, streaks, daily goals, combos,
badges, and weak spots.

## Development

```bash
npm install
npm run dev
```

The app is configured for GitHub Pages at `/geo-quest-pwa/`.

## Checks

```bash
npm run lint
npm run build
```

## Icons

```bash
npm run icons
```

This regenerates the PWA and iPhone home-screen icons in `public/`.
